# Задание: Индекс массы тела

## Условие

В классе **`BmiTask`** реализуйте программу, которая вычисляет **индекс массы тела (ИМТ)** по формуле:

- ИМТ = вес(кг) / (рост (м) * рост (м))

---

### Программа должна:

1. Спросить у пользователя:
    - Вес (в килограммах)
    - Рост (в метрах)
2. Вычислить значение ИМТ по формуле.
3. Вывести ИМТ с точностью **до двух знаков после запятой**.

Пример корректного ввода:

```
Введите ваш вес (в кг): 68
Введите ваш рост (в метрах): 1,75
```

Пример корректного вывода:

```
Ваш индекс массы тела (ИМТ): 22.20
```

---
